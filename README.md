# EasyTopics

**IMPORTANT:** Under active development/reworked. This started as my solo project for the M.Sc. seminar “Practical Applications of Large Language Models” at LMU Munich. Frontend proudly presented by an early version of ChatGPT (GPT-3.5).  [sfohr/easytopics-seminar](https://github.com/sfohr/easytopics-seminar/).

EasyTopics is a web app for question-guided topic modelling of open-ended text. For a question or multiple questions you define, an LLM extracts the relevant part of each response. Only these extracted, and possibly pasted, answers are clustered, so the topics reflect your question rather than whatever dominates the raw text.
